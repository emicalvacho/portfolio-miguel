# Guía de Contribución

¡Gracias por tu interés en contribuir a este proyecto! Este es un portafolio personal, pero siempre estoy abierto a sugerencias y mejoras.

## Cómo Contribuir

1. Fork el repositorio
2. Crea una rama para tu feature (`git checkout -b feature/AmazingFeature`)
3. Commit tus cambios (`git commit -m 'Add some AmazingFeature'`)
4. Push a la rama (`git push origin feature/AmazingFeature`)
5. Abre un Pull Request

## Estándares de Código

- Usa TypeScript para todos los nuevos archivos
- Sigue las convenciones de nomenclatura existentes
- Añade comentarios explicativos cuando sea necesario
- Mantén el código limpio y legible

## Reportar Bugs

Si encuentras un bug, por favor:

1. Verifica que el bug no haya sido reportado ya
2. Abre un issue con una descripción clara del problema
3. Incluye pasos para reproducir el bug
4. Añade capturas de pantalla si es posible

## Sugerencias

Las sugerencias son bienvenidas. Por favor:

1. Abre un issue con la etiqueta "suggestion"
2. Describe la sugerencia de manera clara
3. Explica por qué crees que sería útil

¡Gracias por tu interés!
